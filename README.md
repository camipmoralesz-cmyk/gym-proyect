# gym-proyect

## Nombre de la Organización o Plataforma: Gimnasio Fitness Retro

## Modelo de Negocio / Giro: Centro de acondicionamiento físico y entrenamiento presencial

## Integrantes del Equipo: Camila Morales, Jessica Pacheco, Marian Paraguan

## Entidad de Contexto / Agrupación (ORM): User (o Administrador)(Sirve como el contenedor o rol principal que agrupa, autoriza y supervisa la gestión de los recursos).

## Entidad Principal Gestionable (ORM): Maquina (o Horario)(Es el núcleo central de los datos sobre el cual operan las acciones del sistema: crear, editar, listar y eliminar).

## Propósito de la Sesión (request.session): Autenticación de usuarios por roles (Cliente / Administrador / Superadministrador) y gestión centralizada de estado de membresías con control de aforos en tiempo real.
